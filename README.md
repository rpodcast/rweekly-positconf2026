## Journey of R Weekly

This repository contains the source materials for the lightning talk **For the community, by the community: The 10-year journey of R Weekly powered by open-source** presented during the 2026 Posit Conference. 

You can view the slides at [rpodcast.github.io/rweekly-positconf2026](https://rpodcast.github.io/rweekly-positconf2026).

## Abstract

For a decade, R Weekly has highlighted the innovations, creativity, and novel resources tailored to the R language across data science. Built and sustained by a small, volunteer curator team, the project demonstrates how open-source values—transparency, collaboration, and shared ownership—can power a lasting community initiative. This talk explores how R Weekly evolved, the workflows and infrastructure that keep it running, and the lessons learned from ten years of amplifying innovation. This talk will demonstrate how community-driven curation can strengthen ecosystems and inspire sustainable open-source contributions.
